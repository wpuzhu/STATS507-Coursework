## Project Guideline
This project investigates the preoperative prediction of lymphovascular invasion (LVI) in endometrial cancer using multi-modal MRI-based radiomics features (T1, T2, and ADC).

Both supervised learning (baseline models and adaptive fusion networks) and unsupervised learning (clustering and stability analysis) are employed to evaluate predictive performance and uncover intrinsic data structure. Because the two clinical centers contain technically distinct acquisition batches, the analysis includes explicit center harmonization (ComBat), fitted on training data only.

### Dataset
The original data for the final project are located in the `multi_omics` folder, which contains four primary datasets corresponding to T1-, T2-, ADC-derived features (`T1.xlsx`, `T2.xlsx`, `ADC.xlsx`; columns `case`, `center`, `Label` = LVI, and 396 radiomic features each), as well as the post-hoc dataset (`post_survey.xlsx`; clinical, imaging-report and pathology variables). Train/test splits and all derived data are generated by the code.

### Reproducing the results
```bash
pip install -r requirements.txt
./run_all.sh
```
`run_all.sh` regenerates every table and figure of both reports from the raw data in about 20–35 minutes on a laptop CPU. All random seeds are fixed (data split 42; models and resampling 507). Logs are written to `results/*/cache/` (git-ignored).

The notebooks in `code/` document the original step-by-step development and write intermediate CSV files to `multi_omics/`. Most functions and models are run with fixed random seeds, but if certain code blocks are executed independently, slight variations in randomized results may still occur. The scripts in `code/pipeline` reproduce the notebook analysis exactly (setting "Original (raw z-score)") and extend it with harmonization.

### Analysis overview
1. **Cohort.** Patients with complete T1, T2 and ADC features (n = 329; 77 LVI+); stratified 80/20 train/test split (seed 42).
2. **Center harmonization.** Center 2 contains two acquisition batches (C2a, C2b), detected without labels from run-length texture features recorded on a different scale. Compared settings: original raw z-score, log / Yeo-Johnson transform without harmonization, ComBat by center, and ComBat by acquisition batch (primary). All transforms are fitted on the training data only.
3. **Supervised learning.** ANOVA-F selection (k = 50) and |r| > 0.8 filtering; logistic regression and linear SVM for every modality combination; late fusion; RBF kernel models; threshold tuning; progressive fusion networks. Robustness: repeated 5-fold CV with the whole pipeline inside each fold, center-1-only CV, leave-one-center-out validation.
4. **Unsupervised learning.** Single-modality spectral clustering (ARI stability, consensus PAC) on original and harmonized features, with cluster composition by LVI and acquisition batch. The unsupervised extension adds MOFA+ integration, k-means with silhouette / ARI / PAC selection of k, and post-hoc clinical analysis.

### Data caveats
* Acquisition batch is confounded with the outcome: batch C2b contains no LVI-positive patient, and the center-2 LVI-positive patients form a separately extracted block. Harmonization cannot separate batch from LVI under this design.
* Cross-file consistency checks (`code/unsupervised_extension/05_data_integrity.py`) show weak agreement between tumor volumes across sequences in parts of the cohort; patient linkage should be verified against source records.
* Two implausible post-hoc values are set to missing (p53 = 11, PR = 808%).
