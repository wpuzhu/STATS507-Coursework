# STATS507-Coursework
## Course Description
This course surveys data science tools and frameworks that are currently used in academia and industry. The first part of this course is an accelerated introduction to the Python programming language, with an emphasis on using object-oriented and functional programming techniques for data analysis. The second part covers methods for handling structured data (regular expressions, HTML/JSON, SQL), data visualization, numerical computing, version control, and the UNIX/Linux command line. The third part of this course is an introduction to deep learning and/or large-scale distributed computing.

## Final Project: Multi-modal MRI for Identifying Lymphovascular Invasion in Endometrial Cancer
This project investigates the preoperative prediction of lymphovascular invasion (LVI) in endometrial cancer using multi-modal MRI-based radiomics features (T1, T2, and ADC) from two clinical centers. It consists of two reports:

| Report | Question | Code | Results |
|---|---|---|---|
| **Supervised Report** (`report/Supervised_Report.tex`) | How well can LVI be predicted, before and after center harmonization? Baseline models, adaptive fusion networks, single-modality spectral clustering | `code/supervised_report` | `results/supervised_report` |
| **Unsupervised Extension** (`report/Unsupervised_Extension.tex`) | Do the harmonized data contain stable patient subgroups, and do they relate to clinical variables? Harmonization tests, MOFA latent space, clustering stability, post-hoc analysis | `code/unsupervised_extension` | `results/unsupervised_extension` |

### Reproducing the results
```bash
pip install -r requirements.txt
./run_all.sh
```
`run_all.sh` regenerates every table and figure of both reports from the raw data in about 30 minutes on a laptop CPU, then refreshes `report/tables` and `report/figures`. All random seeds are fixed (data split 42; models and resampling 507). Logs are written to `results/*/cache/` (git-ignored).

The notebooks in `code/notebooks/` document the original development and write intermediate CSV files to `multi_omics/` (git-ignored). Most functions and models are run with fixed random seeds, but if certain code blocks are executed independently, slight variations in randomized results may still occur. The scripts in `code/supervised_report` reproduce the notebook analysis exactly (setting "Original (raw z-score)") and extend it with harmonization.

### Analysis overview
**Supervised Report**
1. **Cohort.** Patients with complete T1, T2 and ADC features (n = 329; 77 LVI+); stratified 80/20 train/test split (seed 42).
2. **Center harmonization.** Center 2 contains two acquisition batches (C2a, C2b), detected without labels from run-length texture features recorded on a different scale. Compared settings: original raw z-score, log / Yeo-Johnson transform without harmonization, ComBat by center, and ComBat by acquisition batch (primary), all fitted on the training data only.
3. **Supervised learning.** ANOVA-F selection (k = 50) and |r| > 0.8 filtering; logistic regression and linear SVM for every modality combination; late fusion; RBF kernel models; threshold tuning; progressive fusion networks. Robustness: repeated 5-fold CV with the whole pipeline inside each fold, center-1-only CV, leave-one-center-out validation.
4. **Unsupervised learning.** Single-modality spectral clustering (ARI stability, consensus PAC) on original and harmonized features, with cluster composition by LVI and acquisition batch.

**Unsupervised Extension** (all 403 patients)
1. **Harmonization tests.** Six strategies (none, ComBat by center, ComBat by acquisition batch, ComBat with LVI protected, CovBat, within-batch rank-INT) compared with feature-wise location / scale tests, PERMANOVA R², batch silhouette and a random-forest batch classifier.
2. **Latent representation.** MOFA+ integrates T1, T2 and ADC into shared and sequence-specific factors.
3. **Clustering and stability.** k-means on the factor scores, with k chosen from the silhouette width, subsampling adjusted Rand index and consensus clustering (PAC); robustness to the algorithm and the harmonization choice.
4. **Post-hoc analysis.** Clinical, imaging-report and pathology variables compared across clusters, with batch-adjusted and within-center-1 tests and explanatory models.

### Data caveats
* Acquisition batch is confounded with the outcome: batch C2b contains no LVI-positive patient, and the center-2 LVI-positive patients form a separately extracted block. Harmonization cannot separate batch from LVI under this design.
* Cross-file consistency checks (`code/unsupervised_extension/05_data_integrity.py`) show weak agreement between tumor volumes across sequences in parts of the cohort; patient linkage should be verified against source records.
* Two implausible post-hoc values are set to missing (p53 = 11, PR = 808%).
